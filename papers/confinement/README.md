# Confinement notes

These files are retained for provenance.  They are not active paper results.

The set was archived as a unit because its confinement narrative depends on four unsupported
identifications:

1. treating a vector in `ℂ³` as if it decomposed into the trace and traceless parts of a matrix in
   `u(3)`;
2. assigning `π₁(U(1))` and `π₃(SU(3))` defects without constructing the corresponding vacuum/order-
   parameter maps;
3. interpreting linear polarization dephasing and representation compatibility as confinement;
4. treating an ansatz-dependent, dimensionally inconsistent time-link estimate as a derived binder.
