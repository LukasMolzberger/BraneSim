Below is a clean statement of the **space–time Fourier analysis problem** for a **3D brane (material coordinates) embedded in 4D**, with **time as a parameter**.

## 1) Fields to be transformed

Let the material (intrinsic) coordinates be
[
x=(x^1,x^2,x^3)\in\Omega\subset\mathbb{R}^3,\qquad t\in\mathbb{R}.
]

Let the embedding be a 4-vector field
[
\mathbf{X}(x,t)=\big(X^1(x,t),X^2(x,t),X^3(x,t),X^4(x,t)\big)\in\mathbb{R}^4.
]

Choose a reference configuration (\mathbf{X}_0(x)) (e.g., flat brane) and define the displacement
[
\mathbf{u}(x,t)=\mathbf{X}(x,t)-\mathbf{X}_0(x).
]

### Lateral vs amplitudal components

In the common “static gauge” for a nearly flat brane,
[
X^i(x,t)\approx x^i + u^i(x,t)\quad(i=1,2,3),\qquad X^4(x,t)=w(x,t),
]
so you naturally identify

* **lateral displacement:** (\mathbf{u}_\parallel(x,t)=(u^1,u^2,u^3))
* **amplitudal displacement:** (w(x,t)=X^4(x,t))

(If the brane can bend strongly, you can instead project (\mathbf{u}) onto the instantaneous tangent space and normal direction, but the FFT formulation below is unchanged—only the definition of the components changes.)

## 2) The 4D Fourier transform (3D space + time)

For each component (A\in{1,2,3,4}), define the space–time Fourier transform
[
\hat{u}^A(\mathbf{k},\omega)
=\int_{\mathbb{R}}!!dt\int_{\Omega}!!d^3x;
u^A(x,t),e^{-i(\mathbf{k}\cdot x-\omega t)}.
]

Equivalently, you can write the vector form
[
\hat{\mathbf{u}}(\mathbf{k},\omega)
=\int dt\int d^3x;\mathbf{u}(x,t),e^{-i(\mathbf{k}\cdot x-\omega t)}.
]

Here:

* (\mathbf{k}=(k_1,k_2,k_3)) is the **spatial wavevector** (spatial oscillation rate),
* (\omega) is the **temporal angular frequency** (time oscillation rate).

You now have:

* (\hat{\mathbf{u}}_\parallel(\mathbf{k},\omega)=(\hat{u}^1,\hat{u}^2,\hat{u}^3))
* (\hat{w}(\mathbf{k},\omega)=\hat{u}^4(\mathbf{k},\omega))

Each complex coefficient can be written as amplitude times phase:
[
\hat{u}^A(\mathbf{k},\omega)=A^A(\mathbf{k},\omega),e^{i\phi^A(\mathbf{k},\omega)},
]
where (\phi^A) is an angle mod (2\pi) (a “(U(1))-type” phase for that Fourier coefficient).

**Important reality constraint:** if (u^A(x,t)) is real, then
[
\hat{u}^A(-\mathbf{k},-\omega)=\big(\hat{u}^A(\mathbf{k},\omega)\big)^*,
]
so phases at ((-\mathbf{k},-\omega)) are not independent.

## 3) Discrete FFT version (what you actually compute)

On a uniform grid (x_{n}=(n_1h,n_2h,n_3h)) with (n_i=0,\dots,N_i-1) and time samples (t_m=m\Delta t) with (m=0,\dots,M-1),
[
\hat{u}^A[p_1,p_2,p_3,q]
=\sum_{m=0}^{M-1}\sum_{n_1,n_2,n_3}
u^A[n_1,n_2,n_3,m];
e^{-i\left(2\pi\frac{p_1 n_1}{N_1}+2\pi\frac{p_2 n_2}{N_2}+2\pi\frac{p_3 n_3}{N_3}-2\pi\frac{q m}{M}\right)}.
]

The corresponding physical wavenumbers and frequencies (for periodic domains) are
[
k_i=\frac{2\pi}{L_i}p_i,\quad L_i=N_i h,
\qquad
\omega=\frac{2\pi}{T}q,\quad T=M\Delta t,
]
with the usual FFT indexing conventions (positive/negative frequencies via shifting).

## 4) What you extract from it

1. **Dispersion branches**: peaks/ridges in (|\hat{u}^A(\mathbf{k},\omega)|^2) give (\omega=\omega_n(\mathbf{k})).
2. **Mode type**: compare power in lateral vs amplitudal channels, e.g.
   [
   P_\parallel(\mathbf{k},\omega)=\sum_{i=1}^3|\hat{u}^i(\mathbf{k},\omega)|^2,\qquad
   P_\perp(\mathbf{k},\omega)=|\hat{w}(\mathbf{k},\omega)|^2.
   ]
3. **Polarization / mixing**: use the 4×4 cross-spectral matrix
   [
   S_{AB}(\mathbf{k},\omega)=\hat{u}^A(\mathbf{k},\omega),\big(\hat{u}^B(\mathbf{k},\omega)\big)^*,
   ]
   and diagonalize it (or average it over time windows) to find dominant eigenvectors (the mode “polarizations” in (\mathbb{R}^4)).

That is the full, precise FFT problem statement for your **3D brane in 4D** with **lateral (1–3) and amplitudal (4) motion** and **time dependence**.
