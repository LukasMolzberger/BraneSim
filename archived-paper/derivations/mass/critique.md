# Mass Bridge — Critique

This bridge has not yet been independently critiqued because it is new to the framework.

## Potential objections

**(a) Premature without stable soliton.** Without a completed stable soliton solution (matter bridge), the mass argument is premature. The toroidal mode ansatz assumes existence of the U(1) vortex as a stable localized solution; this is exactly what the matter bridge has not yet established.

**(b) E[Ψ_torus] finite ≠ E = mc².** Showing E[Ψ_torus] is finite does not by itself show it equals m·c². A separate normalization argument is required: what sets the amplitude A such that the substrate energy at equilibrium matches the observed electron mass?

**(c) Compton wavelength connection.** The connection to the Compton wavelength λ_C = ℏ/mc requires a separate argument. The equilibrium radius R* from the Derrick balance is set by substrate parameters (k_s, α, a, ρ_m); showing R* = λ_C requires deriving ℏ and c from the same parameters consistently.

## Key strength

This avoids the Higgs mechanism entirely and provides a substrate-native explanation for rest mass, which is more consistent with the deterministic substrate ontology. The toroidal-electron picture (Williamson-van der Mark) is a well-known alternative that predicts the correct magnetic moment; this bridge grounds it in a concrete elastic substrate.
